# NEON PONG

A fast, responsive browser Pong game built with vanilla HTML, CSS and JavaScript.

## Features
- Player vs AI
- Easy, Normal and Hard difficulty
- First-to-5, 10 or 15 matches
- Mouse, keyboard and touch controls
- Pause/resume and rematch flow
- Paddle-angle physics and accelerating ball
- Sound effects with mute toggle
- Rally and match statistics
- Responsive neon arcade UI

Open `index.html` in a browser to play.
