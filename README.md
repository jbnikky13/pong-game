# NEON PONG

A fast, responsive neon Pong arcade game built with vanilla HTML, CSS and JavaScript.

## Features

- Easy, Normal and Hard AI
- Match targets: 5, 10 or 15
- Desktop keyboard + mouse controls
- Mobile touch controls
- Pause/resume and sound toggle
- Stage progression with adaptive music generated in the browser
- Rally speed escalation
- High score, win streak and best rally tracking
- Visual hit, score and stage effects
- Responsive mobile-first arcade UI
- No backend or API keys required

## Run

Open `index.html` in a browser, or deploy the repository as a static site on Vercel.

Music is generated with the Web Audio API, so no copyrighted audio files or external music hosting are required.
